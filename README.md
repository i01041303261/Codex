# CODEX: 끝없는 차원의 모험

무료 웹 브라우저 텍스트 RPG 게임 - 6개의 차원을 탐험하고, 50가지 고유 직업을 각성하며 끝없는 모험을 떠나보세요!

🎮 **게임 플레이 바로가기**: [https://i01041303261.github.io/Codex/](https://i01041303261.github.io/Codex/)

## 🌟 주요 게임 특징
- 📜 **차원 스토리**: 6개 차원에 걸친 서사와 300레벨 공허 차원 보스 레이드
- 🔮 **50개 직업소**: 검성, 대마법사, 차원 여행자 등 50가지 다양한 직업 각성 시스템
- ⚔️ **전술 전투**: 스킬, 콤보, 자동 전투 및 박진감 넘치는 타격 효과음
- 🔒 **계정 시스템**: 회원가입, 로그인 및 멀티 세이브 클라우드 백업 코드 지원
