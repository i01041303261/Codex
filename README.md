## 🌟 주요 게임 특징
- 📜 **차원 스토리**: 8개 차원에 걸친 서사와 최고 1000레벨 만렙 확장, 그리고 Lv.500 심연·Lv.750 apex 차원의 보스 레이드
- 🔮 **50개 직업소 & 승급·초월각성·APEX 각성**: 검성, 대마법사 등 50가지 직업, 1~5차 승급 및 400% 스탯 폭증과 전투 전용 초월기 [시공간 붕괴]를 해금하는 궁극의 초월각성, 그 너머의 **⚡ APEX 각성**(스탯 600% · [APEX: 종말의 기록])까지!
- 🛡️ **방어구(갑주) 시스템**: 몬스터·보스를 **공격**하면 일정 확률(일반 9% · 보스 16%)로 갑주가 드롭됩니다. 16종의 차원별 디자인 × **희귀 / 영웅 / 전설 / 신화 / APEX** 등급. 인벤토리에서 장착하면 **방어력·추가 HP**는 스탯에, **피해감소**는 받는 데미지에 즉시 반영되며, **신화 갑주는 Lv.500 + 🪙 30,000 토큰으로 APEX 등급**으로 각성합니다.
- 🗡️ **차원 검 탐험**: 차원 탐험 화면에서 검을 내리쳐 차원을 가릅니다. 한 번 내리칠 때마다 **3초 쿨타임**(버튼 잠금 + 남은 시간 표시)이 걸려 연타로 인한 중복 실행이 없습니다.
- 🎒 **인벤토리 & 차원 파편**: 1~8차원 보스를 격파하면 그 차원 고유의 **차원 파편**과 첫 격파 **격파 증표**를 획득합니다. 인벤토리에서 아이콘·수량·설명을 확인하세요.
- 🌀 **파편 쓰기**: 8개 차원 포탈에 파편을 하나씩 넣어 모두 봉인하면 한정 칭호 `🌌 여덟 차원의 결속자`를 획득합니다.
- 📅 **출석 보상**: 하루 한 번 출석 체크로 🪙 토큰을 받습니다. 연속 출석으로 보상이 커지고 **7·14·21·28일**째에는 신화 갑주 확정·차원 파편·대량 토큰이 함께 지급됩니다. 보정 상한은 28일차이며 28일마다 사이클이 반복됩니다.
- 📢 **업데이트 공지**: 새 업데이트가 있으면 접속할 때 공지 창이 한 번 뜨고, 닫으면 그 버전은 다시 뜨지 않습니다. 상단 `📢 공지` 버튼으로 지난 공지를 언제든 다시 볼 수 있습니다.
- 🎁 **리딤 코드**: 코드를 입력해 토큰·EXP·칭호·아이템 보상을 받습니다. 같은 코드는 1회만 사용 가능하며, 코드 표는 배포본에 비어 있고 필요할 때 한 줄로 추가합니다.
- ⚔️ **전술 전투**: 스킬, 콤보, 자동 전투 및 박진감 넘치는 타격 효과음
- 🔒 **계정 시스템**: 회원가입, 로그인 및 멀티 세이브 클라우드 백업 코드 지원
- ⚡ **실시간 이벤트 센터**:
  1. 경험치 2배 (EXP 2x) 버닝 이벤트
  2. 무한 룰렛 (Unlimited Roulette) 페스티벌
  3. 행운 100% 증가 (실패 0% & 대성공 폭증) 이벤트

## 🕳️ 일곱 번째 차원 「시공간의 끝 보이드」

> *여섯 조각이 하나로 맞춰진 순간, 완성된 CODEX는 스스로의 마지막 장을 찢어냈다. 기록이 가리킨 곳은 어느 차원에도 속하지 않는 좌표, 모든 것이 끝나는 지점이었다.*

- **입장 조건**: **Lv.500** 이상 (그 아래 레벨은 `🔒 Lv.500 필요` 로 잠깁니다)
- **일반 몬스터**: 보이드 포식자(HP 15,000) · 시공간 잔해 골렘(HP 18,000) · 종말의 눈동자(HP 14,000)
- **최종 보스**: **아크 네메시스 (HP 100,000)** — 모든 차원의 잔해가 가라앉는 심연을 지배하는 최후의 포식자
- **격파 보상**: ✨ EXP · 🪙 토큰 대량 지급 + 도감 칭호 `👑 아크 네메시스 격파자`, `🌑 끝을 넘어선 기록자` (첫 격파 시 보너스 EXP 150,000 · 토큰 80,000)
- **스토리**: 차원 스토리 탭 「최종장: 시공간의 끝 보이드 ― 최후의 포식자 아크 네메시스」 (Lv.500 해금, 클리어 시 `🌑 끝을 넘어선 기록자`)

## 📅 출석 보상 시스템

- **입장**: 상단 메뉴 `📅 출석 보상` 또는 홈 화면의 `📅 오늘의 출석` 카드.
- **판정**: 기기 로컬(한국) 시각 기준 **자정 리셋**. 하루 1회만 지급하며, 같은 날에는 버튼이 `✅ 오늘 출석 완료` 로 잠기고 다음 출석까지 남은 시간이 표시됩니다.
- **연속 출석**: 하루라도 건너뛰면 1일차로 리셋됩니다. 보상은 `100 + (일차-1)×40` 토큰으로 커지고, **28일차가 보정 상한**입니다(28일을 넘기면 1일차 보상부터 새 사이클).
- **주기 보상**: 7일 🎖️ 신화 갑주 확정 + 🪙 1,000 · 14일 🌀 차원 파편 + 🪙 2,000 · 21일 🌀 차원 파편 + 🪙 4,000 · 28일 🪙 10,000 + 신화 갑주 + ♾️ 10 TP.
- **세이브**: `attendance: { lastDate, streak }` 두 값만 저장합니다. 출석 필드가 없던 구버전 세이브도 오류 없이 `streak 0` 으로 시작합니다.

## 📢 업데이트 공지(패치노트) 추가 방법

`index.html`의 `PATCH_NOTES` 배열 **맨 위에 항목 하나만 추가**하면 됩니다. 맨 위 항목(`PATCH_NOTES[0]`)의 `version` 이 세이브의 `noticeSeenVersion` 과 다르면 접속 시 자동으로 한 번 뜨고, 닫으면 확인한 버전이 세이브에 저장되어 다시 뜨지 않습니다.

```js
const PATCH_NOTES = [
  {
    version: "2026.11.20",          // 새 값으로 바꾸면 접속 시 자동 팝업
    date: "2026-11-20",
    title: "🎉 새 업데이트 제목",
    items: [
      "추가된 기능을 한 줄로 적습니다.",
      "수정된 버그를 한 줄로 적습니다."
    ]
  },
  // ... 이전 공지는 아래에 그대로 둡니다 (상단 '📢 공지' 버튼의 목록에 표시)
];
```

- 이전 공지는 지우지 말고 아래에 두면 `📢 공지` 버튼으로 연 목록에 함께 표시됩니다.
- `Codex-` 허브에 내장된 CODEX도 같은 파일을 임베드하므로, 수정 후 `python3 hub-build/build.py` 로 재빌드해 주세요(임베드 시 `event.html` 링크는 절대 경로 유지).

## 🎁 리딤 코드 추가 방법

`index.html`의 `REDEEM_CODES` 표에 한 줄만 추가하면 바로 사용할 수 있습니다.

```js
const REDEEM_CODES = {
  "CODEX-HELLO": {
    label: "오픈 기념",
    rewards: { tokens: 1000, exp: 500, items: { shard1: 1 }, title: "🎁 첫 코드 사용자" },
    usableUntil: "2026-12-31T23:59:59"   // 생략하면 무제한
  }
};
```

- 같은 코드는 계정당 1회만 사용할 수 있고(세이브에 사용 기록 저장), 잘못된 코드·만료 코드는 안내 메시지로 알려 줍니다.
- 현재 배포본에는 공개 코드가 등록되어 있지 않습니다(사용 기록·검증 구조만 준비된 상태).
