  1. 경험치 2배 (EXP 2x) 버닝 이벤트
  2. 무한 룰렛 (Unlimited Roulette) 페스티벌

## 🕳️ 최종 차원 「시공간의 끝 보이드」 (7번째 차원)

> *여섯 조각이 하나로 맞춰진 순간, 완성된 CODEX는 스스로의 마지막 장을 찢어냈다. 기록이 가리킨 곳은 어느 차원에도 속하지 않는 좌표, 모든 것이 끝나는 지점이었다.*

- **입장 조건**: 만렙 **Lv.500** (그 아래 레벨은 `🔒 Lv.500 필요` 로 잠깁니다)
- **일반 몬스터**: 보이드 포식자(HP 15,000) · 시공간 잔해 골렘(HP 18,000) · 종말의 눈동자(HP 14,000)
- **최종 보스**: **아크 네메시스 (HP 100,000)** — 모든 차원의 잔해가 가라앉는 심연을 지배하는 최후의 포식자
- **격파 보상**: ✨ EXP · 🪙 토큰 대량 지급 + 도감 칭호 `👑 아크 네메시스 격파자`, `🌑 끝을 넘어선 기록자` (첫 격파 시 보너스 EXP 150,000 · 토큰 80,000)
- **스토리**: 차원 스토리 탭 「최종장: 시공간의 끝 보이드 ― 최후의 포식자 아크 네메시스」 (Lv.500 해금, 클리어 시 `🌑 끝을 넘어선 기록자`)
