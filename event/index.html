📡 다른 기기 전송 대기 ⚪ 꺼짐
대기를 켜 두면, 다른 기기의 게임 로그인 창에서 같은 6자리를 넣는 순간 이 브라우저의 최신 세이브가 WebRTC 실시간 연결로 바로 전송됩니다. (위 목록의 키 옆 📡 대기 켜기 또는 발급 시 자동으로 켜집니다.)
⚠️ 6자리 복구키는 이 브라우저·기기(localStorage)에 저장돼요. 다른 기기에서는 이 화면의 📡 전송 대기가 켜져 있을 때 6자리만으로 바로 받을 수 있고, 연결이 안 되는 환경(시그널 서버 차단·대기 꺼짐)에서는 CDX3. 전체 세이브 코드를 써야 합니다.
🔄 발급한 키는 플레이하면서 최신 세이브로 자동 갱신되며, 30일 동안 안 쓰면 만료됩니다(이 화면에서 언제든 새로 발급).
